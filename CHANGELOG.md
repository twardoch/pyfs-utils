# Changelog

## Version 0.2 (2026-06-29)

- Migrated build system from setuptools/PyScaffold to hatchling + hatch-vcs
- Replaced `setup.cfg` + `setup.py` with a single modern `pyproject.toml`
- Added ruff and mypy configuration
- Added GitHub Actions CI workflow with matrix testing (Python 3.10–3.13)
- Added automated PyPI publish step triggered on version tags
- Added type hints and improved docstrings to `skeleton.py` and `__init__.py`
- Simplified `__init__.py` to use `importlib.metadata` directly (Python 3.10+)
- Moved heavy backend dependencies (`fs-s3fs`, `fs.dropboxfs`, etc.) to optional extras
- Replaced Sphinx docs with Jekyll site in `docs/`
- Updated README with accurate backend table and install instructions

## Version 0.1 (development)

- Initial scaffold generated by PyScaffold 4.0.2
